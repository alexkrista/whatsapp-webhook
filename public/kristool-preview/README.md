# KRISTOOL M2 Prototype

Klickbarer Frontend-Prototyp der KRISTOOL Informationsfabrik.

## Enthalten

- Mitarbeiterübersicht
- GPS-Fahrten und Privatfahrt-Markierung
- Vergleich GPS / gestempelt / Regie / korrigiert
- Funktion „Wie …“
- Regiebericht-Prüfung
- Material- und Fotoprüfung
- Ergebnisvorschau
- Freigabe-Workflow

## Start

`index.html` im Browser öffnen.

Der Prototyp enthält bewusst noch keine Backend-Anbindung und verändert keine Produktivdaten.
